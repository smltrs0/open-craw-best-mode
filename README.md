# open-craw-best-mode

¡Bienvenido a **open-craw-best-mode**!

Este proyecto distribuye su imagen oficial a través de GitHub Container Registry.

## Descarga o Ejecución de la Imagen Publicada

Puedes descargar y utilizar la imagen oficial desde **ghcr.io** con Docker de la siguiente manera:

```sh
docker pull ghcr.io/smltrs0/open-craw-best-mode:latest
```

_Es posible que debas autenticarte en GitHub Container Registry si la imagen no es pública._

Para ejecutar la imagen:

```sh
docker run --rm ghcr.io/smltrs0/open-craw-best-mode:latest
```

Consulta [la documentación oficial de GitHub Container Registry](https://docs.github.com/es/packages/working-with-a-github-packages-registry/working-with-the-container-registry) si tienes dudas sobre la autenticación o el uso de imágenes privadas.
